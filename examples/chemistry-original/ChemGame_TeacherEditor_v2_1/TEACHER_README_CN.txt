ChemGame 教师版使用说明（编辑器 v2）
====================================

一、两个程序
------------
ChemGame.exe
    上课答题使用。

ChemGameEditor.exe
    老师维护章节和题目使用。

两个程序共用同一个 content 题库目录和同一套 Electron 运行环境。

二、编辑器支持的题型
------------------
1. 单项选择题：一个正确答案。
2. 多项选择题：可设置多个正确答案，学生必须全部选对才得分。
3. 填空题：在“正确答案”框中每行填写一个可接受答案。

三、常用操作
------------
添加章节：点击左上“＋ 添加章节”。
添加题目：先选择章节，再点击“＋ 添加题目”，选择题型。
设置答案：
- 单选：点击选项左侧圆点。
- 多选：勾选所有正确选项。
- 填空：每行填写一个可接受答案。
添加图片：题干或选项旁点击“选择图片/图片”，编辑器会自动复制文件，不需要填写路径。
排序：章节、题目和选择题选项都可以按住“☰”拖动，也可以使用上移/下移按钮。
发布：点击右上“保存并发布”。
测试：保存后点击“打开游戏测试”。

四、未保存修改
--------------
如果直接关闭编辑器且有未保存修改，会弹出三个按钮：
- 保存：保存成功后关闭；若校验失败则保持编辑器打开。
- 不保存：放弃修改并关闭。
- 取消：不关闭，继续编辑。

五、自动备份
------------
每次“保存并发布”之前，程序会在后台自动备份题库，并保留最近 20 份。
这个功能不需要老师手动操作，所以编辑器界面不再显示备份文件夹按钮。

六、重要说明
------------
- 老师正常使用时不要手工修改 JSON 文件。
- 游戏中的题目和选项仍会随机打乱；编辑器中的拖动顺序只是为了老师整理题库。
- 选择题解析尽量不要写“故选A”“答案为B”等固定字母，因为学生看到的选项顺序会随机变化。
- 学习记录保存在 userdata 文件夹，不要删除。
