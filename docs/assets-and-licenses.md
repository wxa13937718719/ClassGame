# Asset and license boundaries

The repository's JavaScript, HTML, CSS, PowerShell, JSON schemas, and build
scripts are ClassGame source code and are covered by `LICENSE`.

Question text and the files under each subject's `static/` directory are
content assets. Before changing the GitHub repository to Public, the publisher
must confirm that every question, PNG/JPG/ICO image, MP3 audio file, and other
bundled media can be redistributed. The source-code license does not grant
those rights.

When an asset is not cleared, replace it with an owned or permissively licensed
asset, remove it, or keep the affected subject private. Record attribution and
the applicable license in the subject documentation when required.
